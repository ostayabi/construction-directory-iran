# Security Policy

## Scope

This repository contains documentation only — no application source code. This policy covers:

- Security issues in this repository itself (e.g., a malicious pull request, compromised maintainer account)
- Responsible disclosure of vulnerabilities you find on the Ostayabi website ([https://ostayabi.ir/](https://ostayabi.ir/))

## Reporting a vulnerability

Please do **not** open a public GitHub issue for a security vulnerability.

Instead, use the contact details published on the official website ([https://ostayabi.ir/](https://ostayabi.ir/)) to report the issue privately. Include:

- A description of the issue
- Steps to reproduce it, if applicable
- Any relevant screenshots or logs

## What to expect

We aim to acknowledge reports promptly and address confirmed issues as quickly as reasonably possible. Please allow time for the issue to be verified and fixed before disclosing it publicly.
