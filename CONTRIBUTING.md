# Contributing

Thanks for your interest in improving this documentation.

فارسی: [راهنمای مشارکت به فارسی](#مشارکت-به-فارسی)

## What kinds of contributions are welcome

- Fixing factual errors or outdated information
- Improving clarity, grammar, or formatting
- Adding a missing Persian or English translation of an existing page
- Fixing broken links

This repository does not contain source code, so contributions are limited to documentation content.

## How to contribute

1. Fork the repository.
2. Create a branch for your change.
3. Edit the relevant Markdown file(s) under `docs/`.
4. Open a pull request describing what changed and why.

## Content guidelines

- Keep claims factual — do not add statistics, awards, or user numbers that are not verifiable.
- Keep English and Persian versions consistent in meaning (they don't need to be literal translations).
- Use relative links (`docs/en/...`) for internal references.

## Reporting issues

If you find an error but don't want to submit a pull request yourself, please open an issue describing the problem and where it appears.

## مشارکت به فارسی

از علاقهٔ شما به بهبود این مستندات سپاسگزاریم.

### چه مشارکت‌هایی پذیرفته می‌شود

- اصلاح خطاهای واقعی یا اطلاعات قدیمی
- بهبود وضوح، نگارش یا قالب‌بندی
- افزودن ترجمهٔ فارسی یا انگلیسی برای صفحاتی که فاقد آن هستند
- رفع لینک‌های خراب

### نحوهٔ مشارکت

۱. مخزن را فورک کنید.
۲. یک برنچ برای تغییرات خود بسازید.
۳. فایل(های) مارک‌داون مربوطه را در پوشهٔ `docs/` ویرایش کنید.
۴. یک پول‌ریکوئست همراه با توضیح تغییرات ثبت کنید.

### اصول محتوایی

- ادعاها باید واقعی باشند — از افزودن آمار، جوایز یا تعداد کاربر که قابل تأیید نیست خودداری کنید.
- معنای نسخه‌های فارسی و انگلیسی باید هم‌راستا باشد (نیازی به ترجمهٔ کلمه‌به‌کلمه نیست).
