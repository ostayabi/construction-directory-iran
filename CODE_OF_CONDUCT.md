# Code of Conduct

## Our commitment

We want participation in this repository to be a respectful, harassment-free experience for everyone, regardless of experience level, nationality, gender, religion, or background.

## Expected behavior

- Be respectful and constructive in issues, pull requests, and discussions.
- Focus feedback on the content, not the person.
- Accept differing viewpoints and factual corrections gracefully.

## Unacceptable behavior

- Harassment, insults, or personal attacks
- Publishing others' private information without consent
- Spam or off-topic promotional content unrelated to Ostayabi's documentation

## Enforcement

Maintainers may remove comments, commits, or contributions that violate this Code of Conduct, and may block repeat offenders from further participation.

## Scope

This Code of Conduct applies within this repository's issues, pull requests, and any other spaces where the project is represented.
