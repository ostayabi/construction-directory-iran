# اوستایابی (Ostayabi)

**مخزن اطلاعاتی رسمی [اوستایابی](https://ostayabi.ir/)** — پلتفرمی برای یافتن استادکاران و ارائه‌دهندگان خدمات ساختمانی در ایران.

🌐 وب‌سایت: [https://ostayabi.ir/](https://ostayabi.ir/)
🇬🇧 English: [README.md](README.md)

---

## درباره این مخزن

این مخزن شامل مستندات و اطلاعات عمومی رسمی اوستایابی است. هدف از ایجاد آن:

- ارائهٔ یک منبع دقیق و رسمی برای افرادی که به‌دنبال اطلاعات دربارهٔ اوستایابی هستند.
- توضیح شفاف و صادقانهٔ هدف و دامنهٔ فعالیت پلتفرم.
- امکان بازبینی، پیشنهاد اصلاح یا مشارکت در بهبود این مستندات توسط هرکسی.

این مخزن **کد منبع نرم‌افزار نیست** و فقط شامل محتوای توصیفی است.

## اوستایابی چیست؟

اوستایابی پلتفرمی برای یافتن استادکاران و ارائه‌دهندگان خدمات ساختمانی در ایران است که حرفه‌هایی مانند ساخت‌وساز، بازسازی، لوله‌کشی، برق‌کاری، جوشکاری، نصب کناف و دیوارهای خشک، کاشی‌کاری، نقاشی، بنایی و نگهداری ساختمان را در بر می‌گیرد.

برای توضیح کامل‌تر، به [docs/fa/about.md](docs/fa/about.md) مراجعه کنید.
